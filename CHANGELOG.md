# Changelog

## [0.1.0.pre.4] - 2026-11-01

- Require Spinner 0.1.0.pre.4 for binary-safe buffered, streaming and WebSocket
  transport on the pinned unmodified Spinel toolchain.
- Add reversible Ruby migrations, status/history, integrity tracking and schema
  snapshots alongside existing SQL migrations.
- Add independent table/column enabled contracts, including native record guards
  and detailed/JSON read-only schema validation.
- Add staged endpoint, action, route, view, table, migration, form, component,
  Stimulus, attachment and job generators with collision protection, dry runs
  and exact JSON change reports.
- Add explicit action callbacks/concerns, bounded multipart uploads, streaming
  downloads and permission-aware attachment metadata/local disk storage.
- Add explicit JSON rendering/parsing, format negotiation, validated input forms,
  CSRF verification helpers, compiled components and Turbo response helpers.
- Vendor pinned MIT-licensed Turbo/Stimulus distributions and generate immutable
  fingerprinted asset registries without requiring a Node build pipeline.
- Add request tests, disposable database helpers, unified quick/full checks,
  optional Git hooks, static application inspection and a native dev rebuild loop.
- Generate versioned project agent instructions and discoverable local skills.
- Add versioned native jobs with inline, test and bounded async adapters; add a
  durable PostgreSQL queue, scheduling/retries/cancellation and separately built
  native workers with Docker/Kamal examples. Delivery is at least once.
- Record the Active Job portability spike and the deliberate smaller native API;
  do not claim Rails Active Job compatibility or production readiness.
- Include Minitest in generated test bundles so request checks work under Bundler.
- Extend native, browser CRUD, PostgreSQL recovery and Linux image verification.

## [0.1.0.pre.3] - 2026-10-29

- Publish the clean-install framework preview with explicit PostgreSQL-backed
  applications, records/queries, compiled views and native application packaging.
